# Contributing

Thanks for looking at safe-vibe. It is three small Python hooks that stop destructive agent commands. Small, focused fixes are the most useful.

## Before you start

- Found a bug or have a question? Open an [issue](https://github.com/nickspiz/safe-vibe/issues/new/choose) or start a [discussion](https://github.com/nickspiz/safe-vibe/discussions).
- Planning something bigger than a few dozen lines? Open an issue first so we can agree on the shape.

## Run the tests

```bash
pip install pytest
pytest
```

## Pull requests

- One change per pull request.
- Say what changed and why, in plain English.
- Add or update a test when behavior changes.
- Update the README if the change is visible to users.

By contributing you agree that your work is released under the MIT license.
